- `const` — 常量声明（711新增）
- `local` — 局部变量声明
- `type` — 类型注解
- `export type` — 导出类型
- `--!strict` — 严格模式
- `--!nonstrict` — 非严格模式
- `function` — 函数声明
- `return` — 返回值
- `if`, `then`, `else`, `elseif`, `end` — 条件语句
- `for`, `while`, `do`, `repeat`, `until` — 循环语句
- `break`, `continue` — 循环控制
